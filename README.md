# lover_chat

以你的身份自动回复微信消息的 agent。它通过网页版微信（wx2.qq.com）收发消息，用大模型模仿你的口吻回复指定的人和群，遇到拿不准的情况就停下来交给你。

> ⚠️ 微信个人号没有官方开放接口，任何自动化都违反《微信软件许可及服务协议》，有被限制登录或封号的风险。建议先用小号测试。替你回复的对象并不知道是程序在回，请自己掂量分寸。

## 能做什么

- **自动回复**：只盯配置里列出的联系人和群，其他消息一概不碰。回复前先等几秒，收齐对方连发的消息再回。
- **像你**：用人设、你说过的原话、最近 40 条聊天和长期记忆来生成回复。每次回复都是「先接住对方，再抛一个话题」。
- **和女生聊天**：规则来自对中文聊天建议和恋爱心理研究的调研（已剔除 PUA 套路），分「刚认识 / 暧昧 / 恋爱」三档分寸，附约 30 组示例对话。
- **长期记忆**：每攒 15 条新消息，自动整理出值得长期记住的事（对方的喜好、近况、带日期的计划、你们的梗、你说过的关于自己的话），存在 `data/memory_<对话>.json`，可以手动修改。
- **主动开话题**：对话冷场一段时间后，接着之前聊过的事主动开口（可按对话开关，有每日上限和时段限制）。
- **多道把关**：
  - 生成后先过代码规则（不替你承诺、不编你的事、不复读、不重复自己的梗、不说 AI 腔），再交给模型审核员检查，不合格就重写。
  - 对方起疑、约见面、生气、谈钱时，转交给你。

## 你怎么控制它

| 操作 | 效果 |
|---|---|
| 在项目目录建 `PAUSE` 文件 | 全部暂停，删掉恢复 |
| 建 `RESUME` 文件 | 解除所有对话的暂停，并补回还没回的消息 |
| 在某个对话里亲自发言 | 那个对话暂停 10 分钟（可按对话设置，`0` 表示不暂停） |
| 在文件传输助手里写怎么回 | 程序转交后，照你的意思回。最准的用法是**引用那条转交提醒**再写，会回到那条提醒对应的对话；也可以开头写「对话名：」，或者直接写（回到最近一次转交的对话） |
| 改 `status.txt` | 告诉它你现在在干嘛，不用重启 |
| 以 `HUMAN_MARKS` 里的标记加冒号开头发消息 | 你自己的「本人发言」标记，程序永远不会用它 |
| Ctrl+C | 退出 |

## 安装

需要 macOS 或 Linux、Python 3.11+、Google Chrome，以及一个阿里云百炼（DashScope）的 API key。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env              # 填 DASHSCOPE_API_KEY
cp config.example.py config.py    # 填你的人设和要自动回复的对象
```

`config.py` 里最影响效果的三样：

1. `ME`：你的基本情况。没写的事，模型只会含糊带过。
2. `MY_SAMPLES` 和每个对象的 `samples`：你说过的原话，越多越像你。
3. 每个对象的 `about`：你们的关系、对方的情况。

## 运行

```bash
.venv/bin/python bot.py
```

第一次会弹出一个 Chrome 窗口，用手机扫码登录网页版微信，登录状态保存在 `.wx_profile/`。网页版同一时间只能登录一处。如果开着代理，wx2.qq.com 偶尔会连不上，程序会自动重试。

## 测试提示词

```bash
.venv/bin/python tools/eval_girl.py v3
```

用 20 个女生聊天场景 × 2 种关系阶段跑一遍回复流程，结果存到 `data/eval_v3.txt`，可以和之前的版本对比。这一步不会发出任何消息。

## 工作原理

```
wx2.qq.com（Playwright 控制的 Chrome）
  └─ hook.js 挂在网页版的 chatFactory.messageProcess 上，把新消息推给 Python
bot.py：匹配对象 → 记录 → 等对方说完 → reply.compose()
  reply.py：起疑/约见面检查 → 生成 → 代码规则 → 审核员 → 合格就发，不合格重写或转交
  memory.py：后台整理长期记忆
  llm.py：DeepSeek（DashScope OpenAI 兼容接口）
发送：hook.js 里的 __lcSend 调网页版自己的发送流程
```

## 目录

| 文件 | 作用 |
|---|---|
| `bot.py` | 主程序：浏览器、消息分发、暂停/转交/主动开话题 |
| `hook.js` | 注入网页版微信的收发钩子 |
| `reply.py` | 生成、检查、审核、重写 |
| `prompts.py` | 所有提示词和代码规则 |
| `memory.py` | 长期记忆 |
| `llm.py` | 模型调用 |
| `config.example.py` | 配置模板 |
| `tools/eval_girl.py` | 女生聊天测试集 |
